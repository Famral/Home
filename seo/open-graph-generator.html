                                    og:title
                                    Required
                                    40 – 60 characters
                                    The headline of your object as it should appear in the social graph. Avoid
                                        generic names like "Home" or "Index".
                                

                                

                                    og:type
                                    Required
                                    —
                                    The schema type of your content (e.g., website,
                                        article, product, profile). Defaults to
                                        website.
                                    
                                

                                

                                    og:image
                                    Required
                                    1200 x 630 px (1.91:1)
                                    The full HTTPS URL of the image that should represent your content. Max file

                                    og:url
                                    Required
                                    —
                                    The canonical URL of your page. Consolidates all social likes, shares, and
                                        analytics onto one master URL.
                                

                                

                                    og:description
                                    Recommended
                                    55 – 160 characters
                                    A concise 1 to 2 sentence summary describing the content. Platforms truncate
                                        descriptions exceeding 160-200 chars.
                                

                                

                                    og:site_name
                                    Recommended
                                    2 – 4 words
                                    The global brand or umbrella website name (e.g., "Famral", "The New York

                                    og:locale
                                    Optional
                                    Format: language_TERRITORY
                                    Defines content language. Defaults to en_US if omitted. Examples:

Designing the perfect social share graphic requires adhering to standard viewport ratios so

                        How to Implement Open Graph in Modern Web Stacks
                    


                    

                        
                        
                        
                        
                    


                    
                    

                        <!-- Place directly inside your document's <head> section
                            -->
                        <meta property="og:title" content="Your Page Title" />
                        <meta property="og:description" content="Your description" />
                        <meta property="og:image" content="https://example.com/banner.png" />
                        <meta property="og:url" content="https://example.com/page" />
                        <meta property="og:type" content="website" />
                        <meta name="twitter:card" content="summary_large_image" />
                    


                    
                    

                        // In your app/page.tsx or app/layout.tsx (Next.js 13+ App
                            Router)
                        export const metadata = {
                        title: 'Your Page Title',
                        description: 'Your page description',
                        openGraph: {
                        title: 'Your Page Title',
                        description: 'Your page description',
                        url: 'https://example.com/page',
                        siteName: 'Your Brand',
                        images: [
                        {
                        url: 'https://example.com/og.png',
                        width: 1200,
                        height: 630,
                        alt: 'Preview banner',
                        },
                        ],
                        locale: 'en_US',
                        type: 'website',
                        },
                        twitter: {
                        card: 'summary_large_image',
                        site: '@yourhandle',
                        },
                        };
                    


                    
                    

                        // Using react-helmet or react-helmet-async in Single Page
                            Applications
                        import { Helmet } from 'react-helmet-async';

                        function MyPage() {
                        return (
                        <>
                        <Helmet>
                        <title>Your Page Title</title>
                        <meta property="og:title" content="Your Page Title" />
                        <meta property="og:description" content="Your description" />
                        <meta property="og:image" content="https://example.com/og.png" />
                        <meta name="twitter:card" content="summary_large_image" />
                        </Helmet>
                        <div>Your Content...</div>
                        </>
                        );
                        }
                    


                    
                    

                        // Option 1: Modern SEO Plugins
                        // Install Rank Math or Yoast SEO. Under the "Social" tab on each
                            post/page,
                        // customize the Facebook & Twitter title, description, and
                            preview image directly.

                        // Option 2: Add programmatic hook in your theme's
                            functions.php
                        add_action('wp_head', function() {
                        if (is_single()) {
                        global $post;
                        $thumb = get_the_post_thumbnail_url($post->ID, 'full');

                        });
                    


                


            

        


        
        

            

                

                    Help & Answers
                    
Frequently Asked Questions

                    
Everything you need to know about social meta tags, caching, debugging, and
                        search optimization.

                


                


                    

                        
                        

                            The Open Graph protocol was created by Facebook in 2010 to allow any web page to become a
                            rich object in social graphs. By inserting structured
                            <meta property="og:*"> tags into your HTML document's
                            <head>, you explicitly tell Facebook, Twitter/X, LinkedIn, Discord, and
                            WhatsApp which title, description, image, and canonical URL to render when someone shares
                            your page.
                        

                    


                    

                        
                        

                            The four mandatory tags are:
                            
    
                                
  • og:title — The headline of your content.
    • 
                                
  • og:type — The object type (usually website or
                                    article).
                                
    • 
                                
  • og:image — An absolute HTTPS image URL (1200x630 px).
    • 
                                
  • og:url — The canonical web address of your page.
    • 
                            

                            In addition, og:description, og:site_name, and
                            twitter:card are strongly recommended for maximum engagement.
                        

                    


                    

                        
                        

                            The optimal Open Graph image dimension is 1200 × 630 pixels, with an
                            aspect ratio of 1.91:1. This ensures high-definition rendering on desktop
                            and mobile retina screens. Always keep critical text and focal artwork within the center 800
                            × 420 px safe area to prevent clipping when square crops are generated by mobile apps.
                        

                    


                    

                        
                        

                            Open Graph tags are not a direct algorithmic ranking factor for Google organic web search.
                            However, they dramatically improve your link's click-through rate (CTR), engagement, and
                            shares across social platforms. Higher social referral traffic, brand discovery, and social
                            signals correlate strongly with organic visibility and natural backlink acquisition.
                        

                    


                    

                        
                        

                            Social platforms cache metadata for days or weeks. To force a refresh:
                            
    
                                
  1. Visit the official Facebook Sharing Debugger, enter your URL, and
                                    click "Scrape Again".
    2. 
                                
  2. For LinkedIn, run your URL through the LinkedIn Post Inspector to
                                    purge its internal cache.
    3. 
                                
  3. For WhatsApp or stubborn networks, append a version query string to your image URL
                                    (e.g. https://example.com/banner.png?v=2). This forces their scraping
                                    bot to fetch the new image immediately.
    4. 
                            

                        

                    


                    

                        
                        

                            Open Graph was originated by Facebook (using the property="og:*" syntax), while
                            Twitter Cards are Twitter/X's proprietary format (using name="twitter:*").
                            Twitter natively falls back to Open Graph tags if Twitter-specific tags are absent. However,
                            you must include <meta name="twitter:card" content="summary_large_image">
                            if you want Twitter to render a full-width high-impact banner rather than a tiny square
                            thumbnail.

                            Open Graph images due to potential security vulnerabilities and lack of raster processing in
                            their link scraping engines. Always use raster image formats such as PNG,
                            JPEG, or WebP.
                        

                    


                    

                        
                        

                            If you do not specify Open Graph tags, platforms will attempt to guess your content. They
                            usually scrape the standard HTML <title>, the first available paragraph
                            of text, and an arbitrary image from your page (often a tiny navbar icon, an advertisement
                            banner, or a decorative footer graphic). This leads to distorted, unprofessional previews
                            that suppress user engagement.
