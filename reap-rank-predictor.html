Understanding REAP State Merit Rank & Registration Process

The Rajasthan Engineering Admission Process (REAP) is organized by the Centre for Electronic Governance (CEG), Jaipur for admissions into B.E./B.Tech/B.Arch courses across Rajasthan government and private engineering colleges. Merit ranks are calculated based on valid JEE Main NTA scores and Class 12th PCM percentages.

Key Factors Influencing REAP State Merit Ranks

  • JEE Main Percentile Priority: Candidates with a valid JEE Main NTA score receive primary priority in the REAP state merit list for engineering seats.
  • State Candidate Pool Size: Unlike national AIR which spans ~12 lakh candidates, REAP state merit rank is computed only among ~1.2 to 1.5 lakh Rajasthan registrants, resulting in a much better numerical state rank.
  • Class 12th PCM Percentage: Class 12th PCM percentage serves as the tiebreaker when two candidates hold identical JEE Main percentiles.
  • 85% Home State Reservation: 85% of sanctioned seats in government and private colleges are reserved for Rajasthan domicile (HS) candidates across vertical categories.

REAP Merit Rules & Category Reservations

Summary of REAP state merit compilation rules, domicile status, and category-wise reservation breakdown for Rajasthan engineering admissions.

Eligibility & Merit Compilation

  • Minimum Percentile Requirement: Minimum 20 percentile aggregate in JEE Main NTA score for REAP registration eligibility.
  • Minimum 12th Marks: Pass in 10+2 with Physics, Mathematics & Chemistry with minimum 45% aggregate (40% for reserved categories).
  • Home State vs Other State Pool: 85% seats reserved for Rajasthan Domicile (HS quota) candidates; 15% seats for All India Quota (OS).

Category Reservations

  • SC / ST / OBC / EWS / MBC: Vertical reservations applicable for Rajasthan domicile candidates (SC 16%, ST 12%, OBC 21%, MBC 5%, EWS 10%).
  • TFWS Reservation: 5% additional supernumerary seats in every branch for Tuition Fee Waiver Scheme eligible candidates.
  • Horizontal Quotas: 25% horizontal reservation for female candidates, PwD, and Defence personnel dependents across categories.

Frequently Asked Questions

What is the REAP Rank Predictor and how does it work?
The REAP Rank Predictor is a free tool that estimates your Rajasthan Engineering Admission Process (REAP) state merit rank from your JEE Main NTA percentile. It evaluates historical REAP candidate registration volumes (~1.2–1.5 lakh applicants) to compute your expected REAP state merit rank and category rank.
How is REAP State Merit Rank different from JEE Main AIR?
JEE Main AIR is calculated among ~12 lakh candidates nationally across India. REAP state merit rank is computed only among candidates who register for REAP counselling in Rajasthan (~1.2–1.5 lakh registrants). Therefore, your REAP state rank is numerically much lower (better) than your JEE Main AIR. For example, a JEE Main AIR of 90,000 typically translates to a REAP state merit rank of around 7,500–9,500.
What is the minimum JEE Main percentile required for REAP eligibility?
The minimum JEE Main NTA percentile required for REAP 2026 eligibility is 20 percentile in aggregate. Additionally, candidates must have passed 10+2 with a minimum of 45% marks in PCM (40% for reserved categories).
Are candidates from outside Rajasthan eligible for REAP?
Yes, non-Rajasthan candidates are eligible under the Other State (OS) All India quota, which comprises 15% of the total seats in participating engineering colleges. Note that category reservation benefits (OBC, SC, ST, EWS, MBC) are valid only for Rajasthan domicile (HS) candidates.
How does Class 12th PCM percentage act as a tiebreaker in REAP?
If two or more candidates obtain identical JEE Main percentiles, CEG Rajasthan uses Class 12th PCM percentage as a tiebreaker. Higher PCM percentage results in a better REAP state merit rank.
